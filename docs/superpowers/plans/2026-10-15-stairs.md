# Stone Stairs Implementation Plan

**Goal:** Native Stairs tool below Terrain; reference-style stone flights between adjacent dry terraces; placement preview, deletion, overlap rejection, undo/redo, level persistence, and resident traversal exclusively through stairs.

**Architecture:** UI -> TerrainEditorState/EditCommand -> logical EditorStairs -> affected regional render batches. Immutable BuildingSurfaceSupport finds real rendered terrace boundaries. Navigation receives explicit stair links on the game thread; no GPU work on workers. Preserve existing uncommitted work and saved levels.

1. Logical placement and meshes (primary implementer): `stairs.h/.cpp` defines EditorStairs (id, center position on lower terrace, yaw, lower_terrace; width=3.6m/run=4m), footprint collision/ray picking, deterministic beveled gray stone blocks, boundary snapping. Extend editor state/commands and v4 level format with backward reading v1-v3. CPU checks cover valid/invalid adjacency, duplicate/overlap rejection, deletion, history, persistence, geometry and support edits. Register source in Windows/three Apple targets and CPU check scripts.
2. Native interface (UI implementer): add Stairs below Terrain, retain existing explicit enum IDs (Stairs=3). Five toolbar buttons and new stairs glyph using retired atlas slot7. Existing controls remain intact; Shift+LMB deletes. State/input/preview hooks owned by primary; no UI calls to generators. Verify toolbar order/layout and native hit handling.
3. Resident traversal (navigation implementer): expose `ces_island_resident_system::apply_stairs(vector<EditorStairs>, terrain_config)`; bind links to safe lower/upper landing cells. Approach using existing pathfinding, interpolate height and position on the flight, land on destination terrace. Removal/edit safely cancels transit onto a valid terrace. No stairs preserves former terrace locks. Standalone CPU checks cover up/down traversal, absent links and cancellation. Primary wires scene dirty/update handling.
4. Integration (primary): regionally batch stairs with opaque vegetation/decor geometry, clear grass under footprint, green/red placement aura; update native input/ray picking, register resident links on scene/load/edits. Undo/redo/save/load must update rendering and traversal consistently.
5. Review/verification: code review of combined changes, existing CPU checks plus stairs/traversal checks, Debug+Release builds, native Vulkan placement/removal/history/save/load and resident traversal smoke with screenshots and validation. Metal/OpenGL remain unverified unless available.

**Rulings:** User explicitly requested resident traversal. Stair direction automatically follows the nearest valid rendered ledge. One flight connects exactly one adjacent pair. Delete with Shift+LMB follows existing Trees/Buildings behavior. Terrain changes that invalidate a supporting region remove affected stairs as part of the undoable terrain command. No commit/push requested.
