# F8 render inspector

User scope: left list of every scene pass through final output; right selected name, live On/Off, attachment preview and previously exposed settings. Separate scrolling in list and detail/settings panel when content overflows. Save/initial load retain per-pass settings in GraphicsSettings.json.

Architecture: native UI -> RenderDebugState snapshot/commands -> scene adapter -> generic enabled/bypass controls on engine render techniques. Render dependencies retain their texture allocations; disabled WS passes clear their targets without drawing, disabled scalar passes return neutral clear, disabled color SS effects copy their incoming color. A mandatory debug UI layer is separate from switchable scene UI and is composed at presentation, so disabling scene/UI/final cannot strand the controls. Final-off presents debug UI over black; presentation itself remains valid. Avoid preview feedback by excluding the inspector's own attachment from the selectable list.

Bind RenderDebugState and commands; wheel and visible scrollbars. Remap inspector subtree to ws.debug with no ws.ui copy left, keep interaction blocking, text/font/theme.
